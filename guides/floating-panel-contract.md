# FloatingPanel shared contract

## Common action icons

`site/icons.json` owns the semantic `panelControls` map for `search`, `pin`, `apply`, `reset`, `minimize`, `restore`, and `close`, including each role’s canonical icon and accessible label. Consumers use those roles through their shared UI adapter; they do not define local glyph aliases, labels, or copy icon paths. Panel controls use the same neutral labels across products (`Search`, `Pin`, `Apply`, `Reset`, `Minimize`, `Restore`, and `Close`); product-specific search names and panel lifecycle wording do not replace these shared control roles.

Agentic Design System owns the shared MainPanel, FloatingPanel, and BottomPanel presentation plus Editor Workspace layout. The profile in `site/tokens/shared-ui-profile.json` owns panel width, bottom height, gap, surface colors, border, radius, and shadow. The central stylesheet is `site/floating-panel.css`; it provides `.agentic-panel-main`, `.agentic-panel-bottom`, `.agentic-panel-main-dock`, `.agentic-panel-bottom-dock`, `.agentic-editor-workspace`, and `.agentic-editor-workspace-stage`. The existing `.agentic-base-floating-panel` names remain structural compatibility selectors for Base's adapter. Icons reuse the existing shared `.agentic-icon` class and its centrally owned size and stroke tokens.

Agentic Design System owns the semantic panel-control map, icon rendering runtime, labels, and visual treatment. Base provides a thin React adapter for product callbacks and pressed state. Graph, Commerce, and other products own tab content, action behavior, state, placement, and lifecycle. Graph's MainPanel and BottomPanel use the same central shell presentation as other consumers; product-specific layout behavior can select the shared classes and tokens. Consumers must not define panel token values, panel variants, or local radius, shadow, background, border, header, spacing, or responsive sizing overrides. The shared token profile and shell stylesheet are the only visual source for these values.

`FloatingPanelPanelStyle` accepts positioning and sizing only. The shell root accepts one `rootPlacement` value: `flow`, `dock`, or `viewport-overlay`; the adapter maps it to shared placement behavior. Shell and tab controls do not accept consumer classes, visual CSS overrides, or icon-size and stroke-width props. Tab selection comes only from the parent `activeKey`; keyboard navigation and selected-tab scrolling are shared behaviors. `iconOnly` supports dense rails while each tab keeps its accessible label and title. Icons receive the shared `.agentic-icon` class, which owns dimensions and stroke. Panel headers, tabs, and close controls share `--agentic-row-height` for their block size (38px desktop, 54px on touch or narrow viewports); tabs keep `--agentic-control-height` as the minimum inline size for compact icon-only use. Consumers do not add panel-specific touch-size variants.

Consumer projections bind the exact Design System revision and file digests. Rollback restores those exact prior files and pins together. This source contract does not select package publication, deployment, or production activation.
