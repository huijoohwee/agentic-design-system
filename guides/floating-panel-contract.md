# FloatingPanel shared contract

Agentic Design System owns the FloatingPanel prop types and the shared shell, tab, focus, icon-size, and icon-stroke visuals. The exact declarations live in `site/floating-panel-contract.d.ts`; the central stylesheet is `site/floating-panel.css`. Icons reuse the existing shared `.agentic-icon` class and its centrally owned size and stroke tokens. Graph's MainPanel and BottomPanel use the same `.agentic-base-floating-panel` shell class as other FloatingPanel consumers; hosts own product placement, dimensions, and content flow.

Base owns the React rendering adapter. Graph, Commerce, and other products own tab content, icon artwork, actions, state, placement, and lifecycle. They consume the pinned contract and stylesheet without redefining tab layout, icon dimensions, shell colors, radius, or focus treatment. A host must not add a competing shell class, local radius/shadow/background/border declarations, or a second panel-specific header-row size; the shared token profile and shell stylesheet are the single source for those values.

`FloatingPanelPanelStyle` accepts positioning and sizing only. The shell root additionally accepts the named Base theme-token bridge properties and one `rootPlacement` value: `flow`, `dock`, or `viewport-overlay`. The adapter maps that value to the shared layout. Shell and tab controls do not accept consumer classes, visual CSS overrides, or icon-size and stroke-width props. Tab selection comes only from the parent `activeKey`; keyboard navigation and selected-tab scrolling are shared behaviors. `iconOnly` supports dense rails while each tab keeps its accessible label and title. Icons receive the shared `.agentic-icon` class, which owns dimensions and stroke. Panel headers, tabs, and close controls share `--agentic-row-height` for their block size (38px desktop, 54px on touch or narrow viewports); tabs keep `--agentic-control-height` as the minimum inline size for compact icon-only use. Consumers do not add panel-specific touch-size variants.

Consumer projections bind the exact Design System revision and file digests. Rollback restores those exact prior files and pins together. This source contract does not select package publication, deployment, or production activation.
